Style guide / Color

Choosing color

One accent for anything that can be acted on or is selected. Four semantic tones for state, and only for state. Everything else is neutral. Every swatch and control here is drawn with the product's own stylesheets, so it shows what ships.

Palette

Neutrals carry the page, the accent carries interaction, and the semantic tones carry state. Each tone comes as a text color, a tinted background and a border, used together.

Semantic tones

Success--success, -bg, -border
Warning--warning, -bg, -border
Danger--danger, -bg, -border
Neutral--neutral, -bg, -border
Status amber#DD8A0C, card lights and values

The warning text color reads as brown in large type, so a summary card's amber light and value use the clearer status amber. Warning text, pills and banners keep --warning, which has the contrast small text needs.

Rules for choosing

Pick a color by what it tells someone, never to decorate. If a color doesn't mean something here, the element is neutral.

✓Accent means act or selected

Links, primary buttons, focus rings, the selected row and the main chart series. Nothing else is blue.

✓Tone means state

Green for working or up, amber for needs a look, red for broken or down, grey for off. Never for emphasis or variety.

✓Color one thing per element

A card shows its tone as a light and its value. The label, note and border stay neutral, so the color reads as a signal.

✓Tints go together

A tinted surface uses its tone's -bg and -border, with text in that tone. Pills, banners, error callouts and status codes all follow this.

✕No blue on red

A link on a tinted background takes the tint's color, underlined. The accent clashes with every tone.

✕No tinted card borders

Coloring a whole card's border along with its text turns the card muddy. Let the light carry the tone.

✕No pills for numbers

A change like ↑ 12% is plain colored text beside the value, with an arrow. Past 999% it reads >999%.

✕Don't rely on color alone

Pair a tone with a word, an arrow or a label, e.g. Error, Paused, ↓ 28%, so it reads for someone who can't tell red from green.
